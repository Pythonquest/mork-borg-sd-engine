# Mörk Borg Solitary Defilement Engine

A local, browser-based solo play desk for Mork Borg with Solitary Defilement procedures.

## Features

- Character creation and playbook presets
- Solitary Defilement-style 2d20 move roller
- Dungeon and city crawl generators
- Encounter, trap, reaction, and weak-hit tools
- Campaign thread tracking
- Session journal with import and export
- Local PDF reference links

Open `index.html` in a browser to play. Campaign data is saved in browser storage and can be exported as JSON.
